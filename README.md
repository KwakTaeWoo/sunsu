# 오늘의 저녁 식탁

입력한 지역의 실시간 최저 기온, 비·눈 여부, 현재 계절을 확인해 어울리는 저녁 메뉴 5가지를 추천해 주는 순수 프론트엔드 웹 애플리케이션입니다.

## 주요 기능

- **무료 실시간 날씨 조회**: API 키가 필요 없는 Open-Meteo Geocoding API와 Weather API를 브라우저에서 직접 호출해 지역별 최저·현재·최고 기온, 강수(비·눈) 여부, 풍속을 가져옵니다.
- **최저 기온 및 계절 기반 저녁 메뉴 5선 추천**: 오늘의 최저 기온, 비·눈 여부, 현재 계절에 맞춰 저녁 메뉴 5가지와 이모지, 한 줄 추천 이유를 제안합니다.
- **중복 제외 새로고침**: `마음에 안 들어요, 새로고침` 버튼을 누르면 이전에 추천된 메뉴를 제외하고 새로운 5가지 메뉴를 추천합니다.
- **날씨별 배경 테마 전환**: 맑음, 비, 눈, 흐림, 바람 상태에 따라 화면 배경과 대기 효과가 바뀝니다.

## Vercel 배포 방법

- 모든 파일이 프로젝트 최상위(루트)에 위치해 있어 GitHub 웹의 **Upload files**로 낱개 파일을 그대로 올려도 구조가 깨지지 않습니다.
- 별도의 환경 변수(API 키) 설정 없이 Vercel에서 `Vite` 프리셋(`npm run build`, 출력 폴더 `dist`)으로 바로 배포됩니다.

## 로컬 실행 방법

```bash
npm install
npm run dev
```
